\# Network Security Report



A simple Python project that runs an Nmap scan and generates a easy to read network security report.



\## Purpose



\- Running Nmap service/version detection

\- Saving Nmap results

\- Identifying open TCP ports

\- Displaying detected services

\- Adding simple review recommendations

\- Generating an HTML report



\## Prerequisites



\- Python 3

\- Nmap

\- Git
